# cheme-as-code: conventions for agents

- Python 3.12+, uv, Typer, ruff (line length 100), pytest. Run `uv run pytest -n auto`
  (parallel, as CI does) and `uv run ruff format && uv run ruff check` before every commit.
- `src/chemeascode/templates/project/` is what `cheme init` copies into a plant repository, with
  the bundled skills from `src/chemeascode/{domains/<domain>,project}/skills/<name>/` installed as
  `.claude/skills/<name>/`; files whose name starts with `dot-` are written as `.<rest>`. The
  project-template repository (ChemE-as-Code) is generated from it, never edited directly
  (`.github/workflows/project-template.yml` regenerates it once ci passed on a push to main).
- `src/chemeascode/domains/piping/skills/dexpi-xml/snippets/` and `shapes.md` are generated by
  `scripts/build_snippets.py`; rerun it, do not edit them.
- Use pyDEXPI's loaders, serializers, validation, diff, projection and SVG export. **Do not use
  or expose pyDEXPI's editor commands (`pydexpi.editor`), patches or MCP server**, and do not
  import DigiCo code (`pi_schemas`, `pydexpi_pro`, `digico_*`) or dexpi-js. The platform is about
  agents editing the files directly.
- Every finding a command prints names a file, a line where known, a rule id and a hint.
- `cheme serve` (`serve.py`) is read-only: it never writes to the plant repository. New
  endpoints reuse the command modules (validate, render, diffview, checks), take paths through
  `clean_path`/`Snapshot` and revisions through `Repo.resolve`, and run git with argument lists
  only. fastapi and uvicorn stay in the `serve` extra; the rest of cheme-as-code must not import them.
  It lives in `src/chemeascode/interfaces/api/serve.py`.
- Where code, skills, schemas and integrations go, the import rules and the optional-dependency
  policy: `docs/framework/contributing.md` (architecture: `docs/framework/architecture.md`).
  `tests/test_boundaries.py` enforces the import rules.
- After changing a bundled skill, rerun `scripts/build_skill_manifest.py` and regenerate
  `tests/data/init-manifest.txt` (`uv run python tests/test_init_golden.py`).
- A change that alters the architecture, a public file format or schema, the agent interface
  (commands, findings, skills) or a contract with another ChemE-as-Code repository adds a new
  ADR in `docs/adr/` (or supersedes one) in the same PR; see `docs/adr/README.md`. ADRs are about
  this software; a plant's engineering decisions go in its `DESIGN.md` (`D-NNN`).
