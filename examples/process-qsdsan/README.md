# Water-quality worker contract

This fixture replays declared stream quantities using the Python standard library. The A2/O process-library example runs the biological model. In this directory set `CHEME_QSDSAN_PYTHON` to the absolute path of a trusted Python 3.12+ executable, then run `cheme process simulate --fill` and `cheme process streams --json`. Inspect FEED to see its given pressure alongside the calculated volumetric flow and total nitrogen.
