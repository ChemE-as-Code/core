# P&IDs and DEXPI

P&ID sheets are DEXPI 2.0.1 XML files in `pid/`, loaded through pyDEXPI. `cheme` validates them
(and the lists against them), keeps them in canonical form, renders them and compares them
between git revisions. Agents and people edit the XML directly; see
[Editing and generating sheets](editing.md) for the text helpers and generator scripts.
